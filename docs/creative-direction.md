# Mace Digital homepage creative direction

## Core mandate
The homepage itself must be the proof of craft. It should feel fabricated, commissioned, and engineered rather than assembled from premium-web conventions.

## Brand character
- machined
- architectural
- intelligent
- premium without theatrics
- precise, not decorative
- commercial, not gallery-like

## Anti-direction
Reject all of the following:
- startup/SaaS hero + card grid patterns
- AI-agency glass-card systems
- generic pill nav + generic CTA buttons
- repeated bordered content cards with the same radius/shadow treatment
- icon-row / feature-card layouts
- templated "work cards" and "process cards"
- anything that looks auto-generated because one component style was copied section to section

## Audit of current weak points
1. Top nav still reads like a premium template pill bar.
2. CTA buttons still read like generic launch-page buttons.
3. Hero stat modules are standard feature cards.
4. Most sections still rely on the same rounded bordered frame.
5. Services, work, and process all repeat the same card-grid logic.
6. The inline powered-system stage is stronger than the rest, which makes surrounding sections feel comparatively generic.
7. Outcomes still reads like a standard boxed list.
8. Final CTA is functional but generic.

## Material language
- conductive pathways as machined channels
- titanium/graphite base surfaces
- brushed aluminium highlight seams
- smoked inset viewing windows
- engraved labels instead of badges where possible
- controls should feel like hardware interfaces, not marketing buttons

## Interaction philosophy
- links become channels, toggles, terminals, or command bars
- service items become machine modules with distinct geometry
- work items become specimen bays / dossier windows
- process steps become a calibrated sequence track
- outcomes become a measured response console
- contact becomes a transmission terminal

## Layout philosophy
No two sections should repeat the same composition pattern. The page should feel like one engineered object whose internal subsystems change function as the visitor moves deeper.

## Motion principles
- pulse leads every activation
- section geometry should feel inherited, not reset
- motion should be controlled, weighted, and compact
- no bounce, float, or decorative flourish

## Non-negotiable rules
- if it looks like a template, redesign it
- if two sections share the same layout grammar, break the repetition
- if a control reads like a default web button, replace it
- if a module could belong to another agency, it is unfinished

## Immediate implementation priorities
1. Replace nav and CTA button language with custom control hardware.
2. Remove shared card styling from hero stats, services, work, process, and CTA.
3. Give each section a distinct structural grammar.
4. Keep the conductive system continuous through all redesigns.
5. Verify desktop/mobile/build after the redesign pass.
